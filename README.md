# Number Nest · Math Explorers — Term 1

Páginas HTML interactivas y bilingües (CLIL) de matemáticas con **Milo the Fox**. Son parte del proyecto *Jobs that Protect Life*.

## Contenido

| Archivo | Estación | Tema |
|---|---|---|
| `number_nest.html` | 🪺 Página principal | Recorrido, proyecto, fases, productos y autoevaluación |
| `nn1_value_village.html` | 🏡 Value Village | Números hasta las centenas de millón (valor posicional) |
| `nn2_regroup_ridge.html` | ⛰️ Regroup Ridge | Suma y resta con reagrupación |
| `nn3_chance_creek.html` | 🌦️ Chance Creek | Probabilidad |
| `nn4_graph_grove.html` | 🌳 Graph Grove | Datos: encuestas, tablas y gráficos de barras |

## Qué tiene cada estación

1. Un calentamiento de 5 preguntas que abre la estación.
2. Learning outcome, concepto, estrategias y un laboratorio interactivo.
3. Tres videos en inglés y tres juegos gratuitos. No piden cuenta.
4. La cartilla, Matific y un **taller en Word** con 3 niveles (Reinforcement, Class Level y Deepening).
5. Seis retos con retroalimentación inmediata y una celebración al terminar.
6. Una tarea del proyecto *Jobs that Protect Life*.

## Cómo usarlo

- **En línea:** abre `number_nest.html`. Si GitHub Pages está activado, la dirección es `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/number_nest.html`.
- **Sin internet:** descarga los 5 archivos en una misma carpeta y abre `number_nest.html` con cualquier navegador.

## Privacidad y seguridad

- Las fuentes van incrustadas en cada archivo, así que no se conecta a Google Fonts ni a ningún servidor.
- No hay formularios, analítica ni rastreo, y ningún dato sale del navegador.
- El progreso, las casillas marcadas y la autoevaluación se guardan solo en el navegador de cada estudiante.
- Los enlaces externos (YouTube, juegos, Matific y talleres) se abren solo si el estudiante hace clic, en una pestaña nueva.

## Nota para esta versión de prueba

Este repositorio tiene solo la parte de matemáticas. Algunos enlaces de las estaciones llevan al proyecto (`jobs_that_protect_life.html`) y a las páginas de Science (Tinea) y English (Rowan). Esos enlaces van a mostrar error 404 hasta que se suban esos archivos al mismo repositorio.
