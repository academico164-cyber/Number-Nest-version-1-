3

Concept

What is it and what are its parts?

What is it?

Data is information we collect to answer a question. We organize it in tables and graphs so we can see it quickly and make good decisions.

Parts

  • Title — what the graph is about
  • Vertical axis + scale — counts by 2
  • Bars — the height shows the frequency
  • Categories — the birds on the horizontal axis
  • Mode — the tallest bar: 🐦 Hummingbirds
✏️ Write it! Write what data is and label the parts of the bar graph.

Concrete → Pictorial → Abstract

How we learn it: hands, pictures, symbols
🧠 Psychologist Jerome Bruner showed that we understand ideas in three steps: first we do it with real objects (enactive), then we draw it (iconic), and finally we write it with numbers and symbols (symbolic).

Step 1 · Enactive✋ Concrete

Make a real graph: students stand in lines or stack cubes for each answer to a question.
✏️ Write it! Write the question and how many people chose each answer.

Step 2 · Iconic🖍️ Pictorial

Turn the cubes into a pictograph and a bar graph on grid paper.

5

Strategies

Tools to solve it

Start with a question

Good: “Which job protects life the most for our families?” It has several possible answers.

Tally in groups of 5

Draw 4 lines and cross them with the 5th. Then count by fives.

Choose a scale

Big numbers? Count by 2, 5 or 10 so the graph fits.

Read the key

In a pictograph, one icon can mean more than one. Half an icon = half the value.

Write a conclusion

Use the data: “Most people chose… because…”
